---
description: Verifica y marca los criterios de aceptación de una spec usando el agente verificador del proyecto.
agent: spec-verifier
---

Verifica la spec indicada en `$ARGUMENTS` siguiendo estrictamente el flujo del agente `spec-verifier`.

Si `$ARGUMENTS` está vacío, lista las specs disponibles en `specs/` y pide una ruta, número o slug exacto. No verifiques una spec ambigua.
